# Keep network accounting numeric and incomplete totals explicit

`now` reads all-user, process-only `nettop` cumulative byte counters twice with name resolution disabled, then divides their changes by the actual monotonic interval between readings. It requests exact byte columns without connections, so observing throughput sends no network requests; the interval is reported separately from CPU because sequential source collection causes skew.

PID and start time must match the surrounding `ps` readings. A stable Process absent from both network reports has no observed sockets and a zero change; a one-sided report, changed identity or counter regression has an unknown change. Socket activity entirely between snapshots can be missed. Each direction propagates missing inputs independently through responsible App totals and the host's checked sum, including network Processes absent from the final inventory, rather than presenting a partial total as complete. Host throughput means nettop's TCP/UDP process accounting across all interfaces, including loopback and any repeated proxy accounting, rather than physical-link throughput. A source failure skips network while retaining other observations.
