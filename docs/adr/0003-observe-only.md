# Observe without controlling a Process

Every hostvitals command only observes: none signals, renices, kills, or attaches in order to change a Process. It never runs `sudo`, installs a dependency or prompts; a root-only measurement is Skipped with its reason and the line the caller can elect to run. Because every command already shows what it can observe without changing the Process, the commands themselves satisfy agent-cli's requirement for a command that says what would happen.

Every measurement command samples within one Window and exits, with no daemon, history or authoritative cache. Doctor's independent capability probes are an inventory, not a simultaneous resource measurement. “Since when” comes only from macOS's own counters: a Process's start time, cumulative CPU, lifetime peak Footprint and cumulative disk bytes. Observer overhead is unavoidable; captured memory graphs and persistent tracing sessions are not created. Commands other than profile create no report files.

Profile's raw sample report is the narrow exception authorized by the operator's **RETAIN** ruling in [control#57](https://github.com/sunfmin/control/issues/57#issuecomment-6406527660). It is the measurement's own output for its caller to read, not a report history. Each invocation keeps a distinct owner-only report under `$TMPDIR/hostvitals/`, summarizes those same bytes, and returns its path even when useful observations are partial. Reports remain after exit for the caller to inspect and remove; macOS may purge temporary storage. Doctor continues to discard sample's report. This exception changes artifact retention only, and leaves the observation-only Process contract intact.

For command-line privacy, hostvitals asks for a Process's arguments with `KERN_PROCARGS2` and parses only the argc-delimited argument vector. It never interprets, returns, logs or keeps any environment entry. The buffer is bounded and released at once. It does not claim that environment bytes never enter hostvitals' memory. This is the operator's **buffer** ruling in [control#56](https://github.com/sunfmin/control/issues/56#issuecomment-6406525515), replacing the issue's original absolute “environment is never read” wording: macOS can include environment bytes in the argument buffer, while `ps` destroys the exact argument boundaries needed to preserve public values and redact entire secret values. Native layout and allocation limits stay inside the argument reader; only sanitized arguments cross its interface, and errors contain no raw argument-buffer bytes.
