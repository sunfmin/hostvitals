# Observe macOS on arm64 and x86_64 only

hostvitals observes macOS's own process accounting, entitlements and hardware interfaces. It supports macOS on arm64 and x86_64, an explicit exception to agent-cli's macOS, Linux and Windows release policy: Linux observation would be a separate project with different sources and semantics. Release archives and the Homebrew formula target the two Mac architectures; there is no Windows binary or Scoop manifest.
